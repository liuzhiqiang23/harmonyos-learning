## 安装过程要点

1. **下载**：`developer.huawei.com` 下载中心需要**登录华为账号**才能点下载。点版本行的下载图标不会开新标签页，而是前端发请求拿一个**带签名的临时直链**（`contentcenter-vali-drcn.dbankcdn.cn`），链接里带 `HW-CC-Expire`，**有效期只有 2 小时**——想离线保存安装包要注意这点。
2. **安装器是 NSIS**：支持静默安装。`deveco-studio-6.0.2.670.exe /S /D=D:\DevEco Studio`
   - 坑：NSIS 的 `/D=` **必须是最后一个参数且不能加引号**，路径里有空格也只能裸写。用 `.cmd` 配合 `start "" /wait` 能把命令行原样传进去，避免引号被包上。
3. **SDK 是内置的**：装完 `sdk/default` 就是 API 22 / HarmonyOS 6.0.2 Release（SDK 版本 6.0.2.130），**不需要首次启动再单独下 SDK**。
4. 装完占用约 4GB+（安装在 `D:\DevEco Studio`）。

## 命令行编译（不起 IDE）

内置了 Node.js 和 hvigor，可以直接命令行编译，验证环境很有用：

```bash
cd projects/HelloWorld
export DEVECO_SDK_HOME="D:\DevEco Studio\sdk"
"/d/DevEco Studio/tools/node/node.exe" "/d/DevEco Studio/tools/hvigor/bin/hvigorw.js" \
    assembleHap --mode module -p product=default -p module=entry@default --no-daemon
```

产物：`entry/build/default/outputs/default/entry-default-unsigned.hap`

- 首次运行会通过 npm 装 pnpm（需要联网），之后走缓存就快了。
- `WARN: No signingConfig found for product default` 是正常的：命令行默认出**未签名** HAP。
  要装到真机/模拟器必须签名，签名需要登录华为账号 —— 在 IDE 里
  `File > Project Structure > Signing Configs` 勾选 `Automatically generate signature` 一键搞定。
